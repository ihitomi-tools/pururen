# ぷるれん

> 昔遊んで大好きだった「極小キロバイト宣言！」の『連続連動連結連鎖』を、もう一度遊びたい一心で作りました。私にとっては神ゲーです。

名前の「ぷるれん」は、原作『連続連動連結連鎖』の「連」を、ぷるぷるの仲間たちの「ぷる」と合わせたものです。

原作そのものではなく、記憶と、公開されている説明をもとに作り直した、**非公式のオマージュ作品**です。
原作・配信元・原作者とは関係ありません。盤面の広さ・ゲージの長さ・点数などの数値は、推定で作っています。

## 遊び方
- スタート画面の「**あそびかた**」ボタンで、ルールの説明と、約1分の**チュートリアル**（実際の盤面で、動かして・つなげて・連鎖を見て・ゲージがもどるのを試し、最後に「ちぎって、つなげる」を体験する）が見られます。チュートリアルをしても、保存したゲームやベストスコアは変わりません
- 8×8の盤面に、空きマスが1つ。**盤面の上を指でなぞる**と、なぞった方向に空きマスが動きます（パソコンは矢印キー / WASD、P でポーズ）
- 同じ色の仲間が上下左右に5つ以上つながると、消去ゲージがたまり、満タンで、みんないっしょに消えます
- ゲージがたまる前に、同じ色の仲間をもう1つ足すと、みんなのゲージが0に戻ります
- **このゲームの醍醐味**：つながった仲間は、空きマスで「ちぎって」離しても、同じゲージの仲間のままです。ちぎった仲間を、遠くにある同じ色につなげると、いっしょに大きな塊になって（ゲージも0に戻る）、まとめて消えます。大きな塊ほど高得点で、そのあとの連鎖もつながります
- 消えると、上の仲間が落ちてきて、つながれば連鎖（HIT）。盤面の上に、次に落ちてくる仲間が列ごとに2つ見えていて、**見えたとおりに**落ちてきます
- 石は「ねこ」「プルプル」「宝石」の3種類（はじめは「ねこ」）。画面上の「石：…」ボタンで切りかえられます。「ねこ」は、やさしい色合いの6匹のねこ（ふわふわ、ほんわかした見た目。マスの背景も、猫の色になります）です
- **空きマスが見つけやすくなる工夫**：空きマスは白く光る印で、空きマスの行と列を白い帯と、盤面のふちの白い目盛りで示します。石が消えて空きマスの位置が変わるときは、光の筋でつなぎます。ゲームのはじめには、「空きマス」の札を一瞬出します。「くわしい設定」の「空きマスの見せ方」（ふつう／しっかり／くっきり）で、見え方を選べます（くっきりは、白い帯と印がさらに太く・明るくなります）。「スタート位置」（真ん中／右下）も、「くわしい設定」で選べます（はじめは真ん中）
- スタート画面で選ぶのは、**モード**（時間制限／エンドレス）と**難易度**（EASY＝4色／NORMAL＝5色／HARD＝6色）の2つだけ。そのほかの設定は、「くわしい設定」の中にあります（ゲージの速さ、なぞる感覚、プルプルの強さ、次の仲間の大きさ、時間の減り方・回復など。1〜10の段階で調整できます）
- 時間制限モードの残り時間は、「のこり ○秒」で表示されます（消すと増えます）
- 時間制限モードは、**30秒ごとに「ステージ」が上がります**。はじめの3分は、ゲージが少しずつ速く、消したときの時間の回復が少しずつ減るだけ（気持ちよく遊べます）。**3分をすぎる（7ステージ目〜）と「ラストスパート」**で、時間の減りが30秒ごとに少しずつ（+20%ずつ）速くなり、どんなに連鎖が続く人でも、いつかは時間切れになります。この強さは、「くわしい設定」の「だんだん難しくなる強さ」（1〜10）で変えられます。エンドレスモードと、チュートリアルでは、ステージは上がりません
- **時間が回復する基準**（時間制限モード）：仲間が塊に**新しく加わる**たびに 1つにつき +0.8%、消えたとき 1つにつき +0.2%（バー全体を100%としたとき。時間にすると、5つつなげると約2.4秒、10個の塊に育てると約5秒）。大きな塊を育てている最中から、時間が増えていきます。すでに塊にいる仲間どうしの合体では、二重には増えません。**HITが続くほど、回復が増えます**（HIT2から1つごとに+4%、HIT16以上で最大1.6倍）。回復したときは、バーの上に「+○秒」と出ます。ステージが進むほど、この回復は少しずつ減ります（最小で3割）
- **タイトル画面**：スタート、モード・難易度、「あそびかた」「くわしい設定」「自己ベスト一覧」を、1画面におさめています。ぷるぷる動くロゴと、上から降ってくるねこ（画像ファイルは使わず、すべてコードで描いています。スタートを押すまで、ずっとぷるぷる動きます（ときどき、文字やねこが、ぷるんと揺れます）。スタートを押したり、別の画面を開いたりすると止まります。画面をさわると、ぷるんと弾みます）
- **前回の終わりかたの記録**：アプリが急に止まる原因をさがすため、「くわしい設定」の下に、最近の終わりかた（遊んでいる途中で止まった／画面を離れたあとに閉じた、など）を、この端末の中にだけ4件まで残します。外には送りません
- **フィーバーの音**：始まるときのファンファーレ、フィーバー中だけ流れる軽いリズム、消すときのきらきら音、終わるときの下がる音があります（「おと OFF」では鳴りません）
- **必殺技**（HARD）：消したねこが50匹たまると、1色のねこがぜんぶ消えます（得点 ×2）。はじめは自動で、いちばん多い色を消します。「くわしい設定」で、手動（タップ）で出すことや、消す色を「ボーナス色」「えらぶ」にすることもできます。「えらぶ」のときは、ゲームが止まって、下のねこをタップして色を決めます
- **ラッキーねこ**（どの難しさでも）：ときどき、次に降ってくる予告のねこに星がつき、降りてくると、星がきらきら光るパネルになります（盤面のねこが、急に変わることはありません）。それを含む塊を消すと、得点が2倍、時間制限モードでは時間も3秒増えます
- **フィーバー**（NORMAL・HARD）：HITをつなげると、時間バーの下の「フィーバーゲージ」がたまります。満タンで15秒間、得点が2倍、ゲージも1.5倍長くなります（フィーバー中にHITをつなげると、時間が少しずつのびます。最大30秒）
- **難しさごとの得点の倍率**：EASY ×1 ／ NORMAL ×2 ／ HARD ×4（得点は、消したときの点にかかります。自己ベストは、これまでどおり難しさごとに別々です）
- **HARD（6色）**：つなげにくい分、消えるまでのゲージを1.35倍に長くしています
- **はじめての人向けの案内**：チュートリアルをまだ終えていない（またはやめていない）人には、タイトルの「スタート」の上に、「はじめての人は、ここから！　チュートリアル」の大きなボタンを出します
- **流れ星**：遊んでいるあいだ、背景の夜空に、9〜23秒おきに流れ星がひとつ流れます（ポーズ中・チュートリアル中・動きをへらす設定のときは出ません）
- **ボーナス**：ステージごとに、ボーナスの色が決まっています（緑→青→赤→黄→紫…の順。30秒ごとに交代。エンドレスも同じ）。その色を消すと、得点が1.5倍。時間バーの右の「ねこの絵 ×1.5」が、いまのボーナス色です（石のデザインがねこ以外でも同じです）（チュートリアル中はありません）。自己ベストの記録は、これまでと同じものに続けて記録されます
- **背の高い画面の空きスペース**：ゲーム中も、タイトルと同じ夜空（止めた絵）を敷きます。盤面の上下に十分な空きがあるときだけ、盤面の下に「おうえんねこ」（つないだ色のねこが跳ね、消えた色のねこは大きく跳ねます）、上に「大きなHIT」の数字を出します。空きがない画面では出しません
- **自己ベスト**：モード×難易度ごとに記録します。ゲーム中に自己ベストをこえたら、その場で記録するので、「タイトルにもどる」やアプリが途中で止まっても、記録は残ります。
- **途中保存**：ポーズしたとき・アプリを閉じるとき・遊んでいる間（2秒おき）に、いまのゲームを自動で保存します。タイトル画面の「つづきから」で、続きを遊べます（ゲームオーバー・「このプレイを終了」・新しく始めたときは、保存が消えます）。自己ベストは、「モード（時間制限／エンドレス）× 難易度（EASY／NORMAL／HARD）」ごとに保存され、スタート画面に一覧で出ます（「ゲージの速さ」などの設定を変えても、記録は別になりません）

## 入っているファイル
| ファイル | 役目 |
|---|---|
| `index.html` | ゲーム本体（画像や外部ファイルなし。石の絵も起動時に描いています） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前（ぷるれん）・色・アイコンの設定 |
| `sw.js` | オフラインで遊べるように、ファイルを端末に保存する係 |
| `fonts.css` と `fonts/` | フォント（M PLUS Rounded 1c）。使う文字が入っている部分だけを、このフォルダの中に入れてあります |
| `icon-*.png` | アプリのアイコン（4匹のねこ。Geminiと一緒に作りました） |
| `OFL-M-PLUS-Rounded-1c.txt` | フォントのライセンス本文（SIL Open Font License 1.1）と、著作権表示 |

## 公開のしかた（GitHub Pages）
1. 新しいリポジトリを作り、このフォルダの中身をそのまま入れる
2. Settings → Pages で、公開するブランチと `/ (root)` を選ぶ
3. 表示されたURLを、iPhone / iPad の Safari で開く

## ホーム画面に追加（オフライン用）
1. Safari でURLを開き、共有ボタン →「ホーム画面に追加」（名前は「ぷるれん」になります）
2. 一度、ネットにつながった状態で、ホーム画面のアイコンから開く（このときにファイルが端末に保存されます）
3. それ以降は、ネットがなくても遊べます。ベストスコアや設定も、その端末に保存されます

## 更新のしかた
ゲームの `index.html` を差し替えたら、`sw.js` の先頭の `CACHE = 'puru-v1'` の番号を1つ上げてください（`v2`, `v3`…）。
ネットにつながっていれば、次に開いたときに新しい版に入れかわります。

- 画面に、めずらしい文字を、あとから足したときは、フォントを取り直す必要があります（足した文字だけ、代わりの字体で表示されます）。そのときは、このゲームを作ったときの手順（Claudeに頼めば、やってくれます）で、`fonts/` を作り直してください
